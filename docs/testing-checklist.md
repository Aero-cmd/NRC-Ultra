# NRC Ultra testing checklist

## Launcher
- [ ] Starts without console/runtime errors
- [ ] Profiles open and switch correctly
- [ ] Module settings persist after restart
- [ ] Server profile selection does not overwrite custom settings

## Intel macOS
- [ ] Launch time
- [ ] Idle CPU usage
- [ ] Idle memory usage
- [ ] Minecraft CPU usage
- [ ] FPS average
- [ ] 1% low FPS / frametime stability
- [ ] Chunk loading behaviour
- [ ] Alt-tab/background behaviour

## DonutSMP
- [ ] Correct server profile detected
- [ ] HUD modules load
- [ ] Chat modules work
- [ ] Waypoints persist
- [ ] No client module causes gameplay automation or server-protection bypass

Record Minecraft version, Java version, Mac model/CPU, RAM, render distance, shaders/resource packs, and approximate player/server conditions with every performance report.
